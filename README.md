# Rick 的开源项目门户

这是托管在 GitHub Pages 上的个人开源项目门户网站，展示我（[@L-Angel](https://github.com/L-Angel)）的部分开源项目。

## 在线访问

- 主域名：https://l-angel.net/
- GitHub Pages：https://l-angel.github.io/

## 结构

- `index.html` — 门户首页
- `styles.css` — 样式
- `avatar.png` — 头像
- `CNAME` — 自定义域名配置（请勿删除）
- `.nojekyll` — 让 GitHub Pages 以纯静态方式托管
