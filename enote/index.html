你的笔记，属于你自己

e-note 是本地优先、文件透明、多格式、可自托管同步的跨端笔记应用。

本地优先 文件透明 自托管同步 端到端加密

核心功能

不止是 Markdown 编辑器 —— 富文本、表格、附件、日历、演讲，一个应用全装下。

笔记编辑

Markdown / 纯文本 / 代码，原生编辑 + 即时预览，防抖自动保存。

富文本块编辑器

自研 ENP 格式，块级编辑，支持表格、图片、附件引用。

内置表格 / Excel

表格内核（含公式）+ Excel 编辑器 + 表格引用嵌入。

多格式附件

Word、Excel、PDF、图片、Graffle 统一入库与预览。

自托管同步

WebDAV / 群晖 / SMB / SFTP / S3，数据进你自己的 NAS。

加密

本地静态加密（AES-256-GCM）+ 端到端加密。

历史版本

自动快照，行级 diff，随时回溯与恢复。

日历

内置日历（议程 / 日程），与系统日历双向同步。

演讲模式

讲页模型 + 键位控制，笔记直接当幻灯片用。

AI 能力

写作辅助、标题摘要、RAG 问答，融入笔记场景。

跨端支持

一个应用，覆盖手机、平板、桌面与鸿蒙。

iOS Android HarmonyOS（鸿蒙） Web Windows macOS Linux

常见问题

数据存在哪里？

你本地的普通文件 + 你指定的远端。文件即真相，随时用其它工具打开、备份、迁移。

需要服务器吗？

不需要。自建 NAS 或任意 WebDAV 即可，也可以完全离线本地使用。

支持哪些平台？

iOS / Android / HarmonyOS（鸿蒙）/ Web / Windows / macOS / Linux。

换手机 / 重装 App 数据会丢吗？

不会。卸载不删除本地笔记，重装后重新打开即可加载；换新设备时通过你自己的同步后端（WebDAV / 群晖等）全量恢复。
