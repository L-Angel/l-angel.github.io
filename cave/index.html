Cave

统一的 SQL 数据访问层 —— 用一套 SQL / CQL 语法查询 Elasticsearch、MongoDB 和 MySQL。

GitHub 仓库 Maven Central 完整文档
Java 8+ License Apache-2.0 Build Maven 3.6.3+ Version 0.1.1-SNAPSHOT

特性

用接口签名声明查询，返回类型决定结果映射；支持标准 SQL 子集和可扩展的数据源方言。

多异构数据源

Elasticsearch、MongoDB、MySQL 三种存储，一套语法通吃。

分组与聚合

count / avg / sum / min / max、count(distinct)、GROUP BY / HAVING、多聚合。

能力契约

CapabilityValidator 统一下发能力矩阵，未实现语法显式失败，不静默返回错误结果。

参数绑定

#{} 绑定标量，${list} 展开集合；JDBC 使用 PreparedStatement，不做字符串拼接。

MySQL 连接池

HikariCP 池化连接，支持 JDBC URL、SSL / 时区参数和连接池配置。

Spring Boot Starter

application.yml 配置数据源，自动扫描 @Cave 接口，无需手写 @CaveScan。

架构

CQL 经 ANTLR 解析为 AST，能力校验后由各方言转换为对应存储的查询，再统一映射结果。

CQL / SQL 子集
↓
CqlLexer + CqlParser (ANTLR)
↓
Statements / AST (SelectStatement · Expr · Function)
↓
CapabilityValidator
↓
ElasticSearchQDLDialectResolver→composite / metrics agg→ElasticSearchRvResolver
MongoQDLDialectResolver→$match / $group / $project→MongoRvResolver
JDBC→PreparedStatement(?)→JdbcRvResolver
* JDBC 路径不解析 SQL，直接把参数化后的 SQL 交给 MySQL 执行。

快速开始

引入依赖，声明接口，即可像调用方法一样查询异构数据源。

<!-- pom.xml -->
<dependency>
    <groupId>fun.l-angel</groupId>
    <artifactId>cave-sql</artifactId>
    <version>0.1.0</version>
</dependency>

// 声明查询接口
@Cave
public interface CaveDemo {
    @Select(sql = "select field1, field2 from index1 where f1 = #{param1}", direct = "defaultEs")
    List<Model> queryList(@Param(name = "param1") String param1);
}
返回类型由方法签名决定：List<Model>、单实体、标量、List<String> / List<Integer> 或 List<Map>。实体映射支持无参构造器与 @CField 别名。

数据源配置

使用 Starter 时写在 application.yml；也可以继续使用 @CaveScan + JVM -D 参数或环境变量。

# application.yml
cave:
  packages: [com.example.repository]
  elasticsearch:
    hosts: 127.0.0.1:9200          # 多个节点用逗号分隔
    username: elastic              # 可选
    password: ${ES_PASSWORD:}      # 可选
    default-size: 10000
    group-size: 10000
    enabled: true
    priority: 0
  mongodb:
    host: mongodb://127.0.0.1:27017
    dbname: demo
    enabled: true
    priority: 1
  mysql:
    host: 127.0.0.1:3306
    db-name: demo
    username: root
    password: secret
    # url: jdbc:mysql://127.0.0.1:3306/demo?useSSL=false
    # pool:
    #   maximum-pool-size: 10
    #   minimum-idle: 2
    enabled: true
    priority: 2
ES 地址键为 cave.elasticsearch.hosts，支持 127.0.0.1:9200、 http://es1:9200,http://es2:9200、https://es.example.com:9200； 未写端口自动补 9200。配置优先级：-D > 环境变量 > Starter YAML。 数据源名称固定为 defaultEs、mongodb、mysql，可在 @Select(direct = "mongodb") 中引用。

数据源语义差异

Elasticsearch

字符串等值 / IN / LIKE 默认走 field.keyword；LIKE 区分大小写；无 LIMIT 默认 10000 条；GROUP BY 使用 composite aggregation，HAVING / 排序 / LIMIT 在中间件完成。

MongoDB

单集合查询；LIKE 转为锚定正则（大小写不敏感）；支持 DISTINCT、字段间比较、GROUP BY / HAVING、count / avg / sum / min / max、c_exists / c_keyvalue；不支持 $lookup 和子查询。

MySQL / JDBC

SELECT / JOIN / 子查询 / CTE / 窗口 / GROUP BY 等由 MySQL 原生执行；参数通过 ? 绑定，支持集合参数展开和连接池。

参数与构建

select * from t where f1 = #{p1}          -- 标量参数
select * from t where f1 in (${ids})      -- 集合参数，展开为 (?,?,...)
占位符必须匹配方法参数，否则抛 SqlException；推荐显式使用 @Param(name = "...")。JDBC 的 ${list} 会按元素展开， 过大的列表建议分批查询；${table} 等动态标识符在 JDBC 下不可用。
